# Rover: автономный проезд A → B с объездом препятствий

Автономный мобильный робот в Gazebo Classic: стартует в зоне A, объезжает
препятствия по данным лидара и останавливается в зоне B.

- **ROS:** ROS 2 Humble
- **Симулятор:** Gazebo Classic 11
- **ОС:** Ubuntu 22.04 
- **Робот:** TurtleBot3 Burger, расширенный depth-камерой и GPS
- **Язык:** C++ (узел навигации), Python (launch)

## Структура репозитория

```
src/
├── rover/            # робот, мир, launch, RViz
│   ├── models/rover/ # model.sdf: платформа, лидар, depth-камера, GPS, IMU
│   ├── world/        # wall.world: сцена с препятствиями и зонами A/B
│   ├── launch/       # world.launch.py: запуск всей системы одной командой
│   └── rviz/         # rover.rviz: конфиг RViz
└── rover_nav/        # узел навигации
    └── src/navigator.cpp
```


## Сборка и запуск (одной командой)

```bash
git clone https://github.com/egorsharkov/rover.git nav_ws
cd nav_ws
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
ros2 launch rover world.launch.py
```

Запускается Gazebo с миром, спавнится робот, открывается RViz, и через 10 секунд
стартует навигатор. 


## Сцена

Плоская площадка с препятствиями: две стены (красная и синяя), цилиндр, сфера и
куб. Зона A (зелёный круг) в точке (-6, 0), зона B (красный круг) в точке (7, -1).
Мир привязан к координатам Земли через `<spherical_coordinates>`.

## Робот и сенсоры

| Сенсор | Плагин | Топик |
|---|---|---|
| 2D лидар (360 лучей, 0.12-3.5 м) | `libgazebo_ros_ray_sensor.so` | `/scan` |
| Depth-камера (аналог Orbbec Astra: FOV 60°, 0.4-8 м) | `libgazebo_ros_camera.so` | `/astra/depth/image_raw`, `/astra/depth/points` |
| GPS | `libgazebo_ros_gps_sensor.so` | `/gps/fix` |
| IMU | `libgazebo_ros_imu_sensor.so` | `/imu` |
| Диффпривод и одометрия | `libgazebo_ros_diff_drive.so` | `/cmd_vel`, `/odom` |

Дерево TF: `odom → base_footprint → base_link → {base_scan, camera_link → camera_depth_optical_frame}`.
`odom → base_footprint` публикует Gazebo, остальные трансформы статические (в launch).

## Алгоритм навигации (`rover_nav/navigator`)

Узел принимает `/odom` (поза и курс) и `/scan` (лидар), публикует `/cmd_vel`.
Решение принимается 10 раз в секунду. Лидар делится на секторы: перед роботом
(±20°), слева и справа. Используется конечный автомат:

```
GO_TO_GOAL ──(впереди препятствие)──► TURN ──(путь свободен)──► FOLLOW_WALL
    ▲                                                               │
    └────(цель свободна по лучам и робот отъехал от стены)──────────┘
```

- **GO_TO_GOAL:** пропорциональный поворот к цели и движение вперёд.
- **TURN:** сторона объезда выбирается один раз (где свободнее) и запоминается,
  робот вращается на месте от препятствия.
- **FOLLOW_WALL:** движение вдоль препятствия на расстоянии около 0.5 м.
  Возврат к цели происходит, когда сектор в сторону цели свободен.
  После выхода 1.5 с робот едет прямо, чтобы не вернуться к стене сразу.

Waypoint в системе координат мира: точка B = (7.0, -1.0), допуск достижения 0.3 м.

Параметры: `safe_dist`, `linear_speed`, `angular_speed`, `reach_tol`.
Пример: `ros2 run rover_nav navigator --ros-args -p linear_speed:=0.2`.

## Про GPS

GPS-сенсор установлен в модели и публикует `/gps/fix` (мир задан через
`spherical_coordinates`, lat 55.7717, lon 37.6961). В навигации маршрут задан
в системе координат мира, как допускает задание; позиция берётся из одометрии.
Перевод GPS в локальные метры был реализован формулой
x = Δlon · cos(lat0) · R, y = Δlat · R, но в итоговой версии не используется.

## Ответы на вопросы по электронике

**1. Подключение Orbbec Astra, ультразвуковых датчиков и GPS к Raspberry Pi 5.**
- Orbbec Astra: USB 3.0 (для обеспечения высокой скорости передачиданных).
- Ультразвуковые датчики (например HC-SR04): GPIO. Выход ECHO даёт 5 В, а GPIO
  Raspberry Pi допускает 3.3 В, поэтому нужен делитель напряжения (например 1 кОм + 2 кОм)
- GPS-модуль (например u-blox NEO-6M/M8N): UART.

**2. Питание всех компонентов от одного аккумулятора.**
Один аккумулятор (например Li-ion 3S, около 11.1 В) с главным выключателем.
Напрямую от аккумуляторов питать драйверы моторов.

Далее понижающий импульсный DC-DC преобразователь: отдельный на 5 В с запасом по току (5 А и более) для Raspberry Pi 5

Камера Astra питается от USB-портов Pi, датчики и GPS от 5 В или 3.3 В Pi. 

Общая земля у всех узлов, конденсаторы по питанию, контроль напряжения аккумулятора.

**3. Проверка датчиков без ROS.**
- GPS: `cat /dev/ttyAMA0` (должны идти строки NMEA).
- Ультразвук: скрипт на Python (`gpiozero`), вывод расстояния и сравнение с рулеткой.
- Orbbec Astra: `lsusb` и просмотр изображения утилитой OpenNI2 (`NiViewer`).
- Питание: мультиметр, напряжение 5 В и 3.3 В под нагрузкой.
